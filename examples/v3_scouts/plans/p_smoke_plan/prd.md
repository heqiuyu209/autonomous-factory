# Product

> 由自治软件工厂 PM Agent 生成（RecipeBackend）。

## Goal

提供一个面向「ai meeting notes」的轻量自动化产品，让用户以低成本获得核心价值

## Constraints

- target user: 「ai meeting notes」相关工作依赖手工完成，耗时且易错
- power user: 现有方案对「ai meeting notes」场景适配差，配置复杂

## Acceptance criteria

- [ ] 满足 Goal 描述的最小可用实现

## Primary metric

- 机器验证门全绿（syntax / test / lint）作为客观门槛

## MVP

- 满足 Goal 的最小可用实现
- 配套单元测试（machine verifier 门槛）
- 可被 V1 流水线独立验证与评审
